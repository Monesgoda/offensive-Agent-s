3. SETUP INSTRUCTIONS
--------------------------------------------------------------------------------

PREREQUISITES
- OpenCode CLI (https://opencode.ai) - the agent runtime
- Bash (WSL / Git Bash / Linux / macOS) for the shell scripts
- SQLite3 CLI (optional, for direct findings.db queries)

INSTALLATION
1. Install OpenCode:
       npm install -g opencode-ai

2. Clone or copy this repository into your OpenCode config directory:
       git clone <this-repo-url> ~/.config/opencode
   (On Windows: %USERPROFILE%\.config\opencode)

3. Install the plugin dependency (from the repo root):
       npm install

4. Configure your model provider in opencode.jsonc:
   - Replace "YOUR_MODEL_HERE" with your model identifier
   - Add your provider API key (e.g. ANTHROPIC_API_KEY, OPENAI_API_KEY)

5. Configure MCP servers in opencode.jsonc:
   - burp:    point to your Burp Suite MCP proxy (java + mcp-proxy.jar path)
   - notion:  set your Notion integration token
   - github:  set your GitHub Personal Access Token
   - filesystem: set the workspace root you want to expose
   - memory:  set MEMORY_FILE_PATH (default ~/.config/opencode/pentest/memory.jsonl)

6. Initialize the findings database:
       bash pentest/scripts/init_db.sh

7. Run the environment health check:
       bash pentest/scripts/doctor.sh

8. Configure your first engagement in pentest/scope.json:
   - engagement:  name of the engagement
   - target:      primary target domain
   - in_scope:    list of authorized targets
   - out_of_scope: list of excluded targets
   - rules:       rate limits, no-destructive, no-DoS, require_scope_check,
                  require_user_approval

USAGE
- Agents are invoked by their names (e.g. "run recon tools", "web app pentest",
  "AD attack", "generate payload").
- All agents enforce the scope rules in pentest/scope.json before acting.
- Findings are logged to pentest/findings.db (tables: engagements, hosts,
  services, vulns, credentials, chains, session_log).
- Knowledge extracted from write-ups is stored under pentest/knowledge/.
- Before delegating to a sub-agent, the operator reads its SKILL.md at
  .opencode/pentest/agents/<name>/SKILL.md and passes it as context.

SECURITY NOTES
- This repository is a TEMPLATE. It contains no real engagement data,
  credentials, tokens, or target information.
- Replace all placeholders (YOUR_MODEL_HERE, API_KEY, TARGET_DOMAIN, etc.)
  with your own values before use.
- Never commit findings.db, memory.jsonl, or engagement-specific knowledge
  files to version control.
